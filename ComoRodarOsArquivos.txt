Como rodar arquivos neste repositorio

1) C# scripts (.csx)
- Instale dotnet-script
- Rode:
  dotnet script "caminho\arquivo.csx"

2) Projetos C# (.csproj)
- Entre na pasta do projeto
- Rode:
  dotnet run

3) JavaScript (Node)
- Rode:
  node "caminho\arquivo.js"

4) Python (.py)
- Rode:
  python "caminho\arquivo.py"
