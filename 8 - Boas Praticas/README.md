# Boas Praticas - Guia Profundo (Sem Resumo)

## 1) Por que boas praticas?
Codigo e lido mais vezes do que escrito. O objetivo e clareza.

------------------------------------------------------------

## 2) Nomeacao
- Use nomes descritivos.
- Evite siglas confusas.

------------------------------------------------------------

## 3) Funcoes pequenas
- Uma responsabilidade por funcao.
- Facilita testes.

------------------------------------------------------------

## 4) DRY e KISS
- Evite repeticao.
- Mantenha simples.

------------------------------------------------------------

## 5) Comentarios
- Explique o "por que", nao o "o que".

------------------------------------------------------------

## 6) Code review
- Revise com foco em bugs e legibilidade.

------------------------------------------------------------

## Exercicios
1. Refatorar codigo duplicado.
2. Melhorar nomes de variaveis.
3. Criar checklist de review.
