# Fundamentos - Guia Profundo (C# e JavaScript)

## Como rodar os exemplos C# (.csx)
1. Instale dotnet-script.
2. Rode:
```bash
dotnet script "arquivo.csx"
```

## Como rodar exemplos JS
1. Instale Node.js.
2. Rode:
```bash
node arquivo.js
```

------------------------------------------------------------

## C# - O que e e como usar

### Pontos principais
- Tipagem estatica
- Compilado
- Muito usado em backend (ASP.NET)

### Sintaxe basica
```csharp
int idade = 25;
string nome = "Ana";
Console.WriteLine(nome);
```

### Estruturas importantes
- if/else, switch
- for, while, foreach
- funcoes (metodos)
- classes e objetos

------------------------------------------------------------

## JavaScript - O que e e como usar

### Pontos principais
- Tipagem dinamica
- Roda no navegador e no Node

### Sintaxe basica
```javascript
let idade = 25;
const nome = "Ana";
console.log(nome);
```

### Estruturas importantes
- if/else
- for, while, forEach
- funcoes
- objetos e arrays
