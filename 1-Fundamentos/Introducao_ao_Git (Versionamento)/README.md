# Git (Versionamento) — Guia Basico

## O que e Git?
Git e uma ferramenta para controlar versoes do codigo. Ele guarda o historico das mudancas e permite voltar atras se algo quebrar.

## Conceitos principais
- **Repositorio**: pasta controlada pelo Git.
- **Commit**: um "salvamento" do estado do codigo.
- **Branch**: uma linha de desenvolvimento paralela.
- **Merge**: juntar branches.

## Passo a passo basico
1. `git init` para iniciar o repo.
2. `git status` para ver arquivos alterados.
3. `git add .` para preparar.
4. `git commit -m "mensagem"` para salvar.

## Dicas
- Commits pequenos.
- Mensagens claras.
- Sempre verifique `git status`.

## Exercicios
- Fazer 3 commits pequenos.
- Criar branch, editar e fazer merge.
