# Operadores — Guia Completo

## O que sao operadores?
Operadores sao simbolos que permitem fazer calculos e comparacoes. Em C#, eles sao agrupados em categorias.

## Tipos principais

### 1) Aritmeticos
- +, -, *, /, %

### 2) Relacionais (comparacao)
- ==, !=, >, <, >=, <=

### 3) Logicos
- && (E), || (OU), ! (NAO)

### 4) Atribuicao
- =, +=, -=, *=, /=

### 5) Ternario
- condicao ? valor1 : valor2

## Exemplo simples
```csharp
int a = 10;
int b = 3;
Console.WriteLine(a + b); // 13
Console.WriteLine(a > b); // true
```

## Erros comuns
- Confundir == com =
- Divisao inteira (ex: 5 / 2 = 2)
