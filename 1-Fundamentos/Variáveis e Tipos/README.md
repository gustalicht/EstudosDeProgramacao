# Variaveis e Tipos — Guia Completo

## O que e uma variavel?
Uma variavel e um "espaco" onde guardamos valores para usar depois.

## Tipos comuns em C#
- `int`: numeros inteiros
- `double`: numeros decimais
- `bool`: verdadeiro/falso
- `char`: um caractere
- `string`: texto

## Exemplo simples
```csharp
int idade = 25;
double altura = 1.75;
string nome = "Gustavo";
```

## Dicas
- Use tipos certos para evitar erros.
- `var` deixa o C# inferir o tipo.
- `const` cria constantes.

## Exercicios sugeridos
- Calculadora simples.
- Conversores de unidades.
- Contador de palavras.
