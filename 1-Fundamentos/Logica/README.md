# Logica de Programacao — Guia Completo

## O que e logica?
Logica e a capacidade de organizar passos para resolver um problema.

## Como treinar
1. Leia o problema com calma.
2. Quebre em passos pequenos.
3. Resolva cada passo com variaveis e condicionais.
4. Teste com exemplos simples.

## Dicas
- Pense no algoritmo antes do codigo.
- Escreva o que voce quer fazer em portugues primeiro.
- Comece com casos pequenos.

## Exercicios sugeridos
- Inverter string.
- Contar vogais.
- Verificar palindromo.
- Encontrar maior numero.
