## 1) Conceitos base

- **Acoplamento**: dependencia entre modulos.

## 2) Camadas
Separar em apresentacao, aplicacao, dominio, infraestrutura.

------------------------------------------------------------

## 3) Clean Architecture
- Dependencias apontam para o dominio.
- Facilita testes.

------------------------------------------------------------

## 4) Hexagonal
- Portas (interfaces)
- Adaptadores (implementacoes)

------------------------------------------------------------

## 5) Monolito vs Microservices
- Monolito: simples, rapido para iniciar.
- Microservices: complexo, escala melhor.
