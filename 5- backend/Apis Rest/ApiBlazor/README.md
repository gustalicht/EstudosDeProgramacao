# ApiBlazor (Blazor Server) - Guia Detalhado

## O que e?
Blazor permite criar UI com C# no lugar de JavaScript.

## Como funciona
- Componentes .razor.
- Renderizacao no servidor (neste template).
- Estado fica no servidor e eventos sao enviados por SignalR.

## Estrutura
- Components/Pages: paginas
- Components/Layout: layout
- Program.cs: pipeline

## Quando usar?
- Aplicacoes internas.
- Times que preferem C# para UI.

## Exercicios
1. Criar novo componente de lista.
2. Consumir API com HttpClient.
