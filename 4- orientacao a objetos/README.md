# Orientacao a Objetos - Guia Detalhado

## O que e Orientacao a Objetos (OOP)?
E um jeito de programar pensando em "objetos" do mundo real. Cada objeto tem:
- **Estado** (dados)
- **Comportamento** (acoes)

## Por que usar?
- Organizar melhor o codigo.
- Reutilizar partes com heranca e composicao.
- Facilitar manutencao.

## Quatro pilares
1. **Encapsulamento**: esconder detalhes internos.
2. **Abstracao**: mostrar apenas o essencial.
3. **Heranca**: reutilizar e especializar classes.
4. **Polimorfismo**: tratar diferentes tipos de forma uniforme.

## Modelo mental
Pense em uma classe como uma "planta" e o objeto como uma "casa" feita a partir dela.

## Como estudar (passo a passo)
1. Entenda o que e uma classe.
2. Crie objetos e use metodos.
3. Aprenda sobre construtores.
4. Use heranca quando fizer sentido.
5. Use interfaces para contratos.
6. Explore padroes de projeto.

## Pastas desta secao
- Abstracao
- Classes e Objetos
- Interfaces e Design Patterns

## Dica
Comece simples: uma classe com 2 atributos e 2 metodos. Depois aumente.
