# CSS - Guia Detalhado

## O que e CSS?
CSS controla o estilo: cores, tamanhos, layout e animacoes.

## Conceitos principais
- Seletores (elemento, classe, id)
- Box model (margin, border, padding)
- Flexbox e Grid
- Responsividade (media queries)

## Exemplo simples
```css
.card {
  padding: 16px;
  border-radius: 12px;
}
```

## Exercicios
1. Card responsivo.
2. Menu com hover.
3. Animacao com keyframes.
