# CSS - Guia Profundo (Sem Resumo)

## O que e CSS?
CSS controla layout, cores, fontes e animacoes.

## Box Model (fundamental)
Cada elemento tem:
- margin
- border
- padding
- content

## Layouts
- **Flexbox**: alinhamento em uma direcao.
- **Grid**: layout em linhas e colunas.

## Responsividade
- Media queries
- Unidades relativas (%, rem, vw)

## Animacoes
- `transition` para mudancas suaves
- `@keyframes` para animacao real

## Erros comuns
- Não usar box-sizing
- Não testar no mobile

## Exercicios
1. Menu com hover.
2. Card responsivo.
3. Animacao com keyframes.
4. Landing page simples.
