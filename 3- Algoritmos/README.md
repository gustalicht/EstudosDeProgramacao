# Algoritmos - Guia Detalhado (Visao Geral)

## O que e um algoritmo?
Algoritmo e uma sequencia de passos para resolver um problema.

Exemplo simples (somar 3 numeros):
1) Ler A, B, C
2) Somar A + B + C
3) Mostrar resultado

## Por que estudar algoritmos?
- Para resolver problemas de forma eficiente.
- Para entender desempenho (tempo e memoria).
- Para pensar com mais clareza ao programar.

## Como estudar (passo a passo)
1. Entenda o problema.
2. Escreva os passos em portugues.
3. Transforme em codigo.
4. Teste com exemplos pequenos.
5. Analise a complexidade (Big-O).

## Conteudo desta pasta

- Ordenacao (bubble sort)

Sempre compare um algoritmo simples com um mais eficiente para entender o ganho.
