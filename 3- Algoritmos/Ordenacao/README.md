# Ordenacao - Guia Detalhado

## O que e ordenacao?
Ordenar significa colocar elementos em uma ordem (crescente ou decrescente).

## Bubble Sort (basico)
- Compara vizinhos.
- Troca se estiver fora de ordem.
- Repete ate ficar tudo ordenado.

## Passo a passo do Bubble Sort
1. Percorrer o array do inicio ao fim.
2. Comparar elemento atual com o proximo.
3. Se estiverem fora de ordem, trocar.
4. Repetir varias vezes.

## Complexidade
- Melhor caso: O(n) (quando ja esta ordenado e usamos otimização)
- Pior caso: O(n^2)

## Quando usar?
- Apenas para estudo (nao e o mais eficiente).
