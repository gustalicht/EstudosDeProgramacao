# Python - Guia Completo (Sem Resumo)

## O que e Python?
Python e uma linguagem de alto nivel, simples de ler e muito usada em backend, dados, automacao e IA.

## Por que aprender Python?
- Sintaxe direta
- Grande ecosistema
- Ideal para scripts e APIs

------------------------------------------------------------

## Como instalar e usar
1. Instale Python 3.x.
2. Verifique no terminal:
   ```bash
   python --version
   ```
3. Rode um script:
   ```bash
   python arquivo.py
   ```

------------------------------------------------------------

## Ambiente virtual (venv)
Isola dependencias por projeto.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install requests
```
