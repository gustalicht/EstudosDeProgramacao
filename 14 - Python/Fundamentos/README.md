# Fundamentos Python - Guia Detalhado

## 1) Variaveis e tipos
Python usa tipagem dinamica.

Exemplo:
```python
nome = "Ana"
idade = 25
altura = 1.75
```

## 2) Condicionais
```python
if idade >= 18:
    print("maior")
else:
    print("menor")
```

## 3) Loops
- for: percorre colecoes
- while: repete ate condicao

## 4) Funcoes
```python
def soma(a, b):
    return a + b
```

## 5) Colecoes
- list
- dict

- tuple
